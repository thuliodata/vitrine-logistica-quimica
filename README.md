# 🧪 Vitrine Logística - Setor Químico

Sistema desenvolvido em Python (com Gradio e Pandas) para otimização, alocação de transportadoras e gestão de fretes no setor químico.

## 🚀 Funcionalidades
- **Listagem de Cargas:** Visualização em tempo real de coletas e entregas disponíveis.
- **Cadastro de Pedidos:** Interface interativa para inclusão de novas rotas, volumes, tipos de embalagem (IBC, tambor, etc.) e valores de frete estimados.
- **Simulação de Cotações:** Envio automatizado de solicitações de cotação para as transportadoras sugeridas[cite: 2].

## 🛠️ Tecnologias Utilizadas
- Python 3.x
- Gradio (para a interface web interativa)
- Pandas (para manipulação e estruturação dos dados)

## 📌 Como Rodar
O projeto foi validado e roda nativamente no **Google Colab** para evitar conflitos de dependências locais. Basta abrir o arquivo `.ipynb` no Colab e executar as células!
